# Time Count Down

เว็บนับถอยหลังสไตล์ Apple — บอกว่าเหลืออีกกี่ **ปี / เดือน / สัปดาห์ / วัน / ชั่วโมง / นาที / วินาที** จนถึงวันเวลาที่ตั้งไว้

- ใส่ชื่อ (title) ได้ — ไม่บังคับ
- ตัวเลขหมุนแบบ rolling digits, พื้นหลัง aurora เคลื่อนไหว, การ์ดกระจก (glassmorphism), confetti เมื่อถึงเวลา
- คำนวณปี/เดือนตามปฏิทินจริง (เดือนที่มี 28–31 วัน)
- จำค่าไว้ใน browser และเก็บใน URL (`?t=<timestamp>&title=...`) กด **แชร์** เพื่อส่งลิงก์ให้คนอื่นได้
- มี preset: ปีใหม่, สงกรานต์, คริสต์มาส, อีก 100 วัน
- รองรับมือถือ
- โหมดสว่าง/มืด: ตามระบบอัตโนมัติ หรือกดปุ่ม ☀︎/☾ มุมขวาบนเพื่อสลับ (จำค่าไว้)

## ใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้อง build (หรือเปิด GitHub Pages จาก branch หลัก)
